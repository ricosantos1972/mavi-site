# MAVI Streaming+ — site

Site estático (GitHub Pages) + banco Supabase.

- `index.html` — página inicial
- `listas.html` — "Minhas listas": o cliente entra com MAC + Device Key e gerencia as listas (sincroniza com o app)
- `admin.html` — painel do Rico: ativar planos, cortesias, bloquear
- `privacidade.html` — política de privacidade (link exigido pela Google Play)
- `supabase/01-banco.sql` — script do banco (rodar no SQL Editor do Supabase)
